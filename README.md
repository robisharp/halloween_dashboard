# 🎃 Halloween Tableau Dashboard

An interactive **Halloween-themed data visualization dashboard** created using **Tableau** to explore and present data through engaging charts, visualizations, and interactive elements.

## 📊 Dashboard Preview

The dashboard is designed with a Halloween-inspired theme to make the data analysis visually engaging while maintaining clear and meaningful data storytelling.
